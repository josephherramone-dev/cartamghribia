# Card images

Put real card images here and the game uses them instead of the drawn cards.
Any card without an image falls back to the drawn version.

**Names** (any of these work, upper or lower case):

| Suit | Accepted names |
|------|----------------|
| Coins | `dheb`, `oros`, `coins` |
| Cups | `kass`, `copas`, `cups` |
| Swords | `syouf`, `espadas`, `swords` |
| Clubs | `zrawet`, `bastos`, `clubs` |

Ranks: `1`–`7`, `10`, `11`, `12`. Number first or suit first, separated by `-`, `_` or a space:
`1-oros.png`, `oros-1.png`, `12_bastos.jpg`, `7 copas.webp`, …

Optional card back: `back.png` (or .jpg / .webp / .svg).

Formats: PNG, JPG, WebP, SVG, GIF. Best results: all images the same size, portrait, about 2:3 (e.g. 400×600),
cropped to the card edge. Only use images you have the right to use (your own scans/photos, or a set with an open licence).
After adding images, refresh the page (no restart needed).
